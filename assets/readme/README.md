# README banner

Own artwork, generated by `node tools/readme-banner.mjs --png` (the SVGs are the source, the PNGs and
`preview.png` are renders). Grid: 320 x 80 cells, 4 px per cell, 1280 x 320, 1-bit look, own 5x7
pixel font, no Korg assets. The two terror eyes stare at the wordmark; the subtitle is set in two
lines so it stays readable at 640 px.

`banner-dark.svg` is the dark card (#0a0a0b, accent #9ec3d1), `banner-light.svg` the light one.
Use both with `<picture>` so the banner fits GitHub's dark and light themes:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="assets/readme/banner-dark.svg">
  <img alt="Kuhler's GELUMPE: Grafischer Electribe-Leser und -Modifizierer plus Emulator" src="assets/readme/banner-light.svg" width="100%">
</picture>
```

Subtitle text lives in `SUBTITLE` in `tools/readme-banner.mjs` (supported glyphs: the letters used there plus A-Z, `. , ' -`).
