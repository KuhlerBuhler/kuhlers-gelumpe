# Part-Felder über Controller zugeordnet

Gemessen 2026-09-16: Controller auf dem Kanal eines Parts geschickt, den
Pattern-Puffer per SysEx `0x10` vorher und nachher gelesen und verglichen.
MIDI-Kanal N steuert Part N (Kanäle 1, 5, 10 geprüft). Voraussetzung: der
globale Receive Filter steht auf Off.

| CC | Part-Byte | Feld |
|---|---|---|
| 7 | 24 | Amp Level |
| 10 | 25 | Amp Pan |
| 71 | 14 | Resonanz |
| 72 | 21 | EG Decay/Release |
| 73 | 20 | EG Attack |
| 74 | 13 | Cutoff |
| 80 | 36 | Osc Pitch |
| 81 | 37 | Glide |
| 82 | 11 | Osc Edit |
| 83 | 15 | Filter EG Int |
| 85 | 18 | Mod Depth |
| 86 | 17 | Mod Speed |
| 87 | 34 | IFX Edit |
| 104 | 32 | IFX An/Aus |

Für Pan, Pitch und EG Int gilt: in der Datei steht der MIDI-Wert minus 64.
CC 10 mit 100 ergab Dateiwert 36.
