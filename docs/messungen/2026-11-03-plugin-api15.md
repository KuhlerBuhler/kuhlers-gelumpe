# Plugin API 15: Pattern-Setter, Touchpad-X und Tastendruck

Stand 3. November 2026. **Gemessen** im Emulator mit Hacktribe 2.02 (eigene Datei), Korgs Original 2.02 rot und blau,
jeweils mit dem BLECH-Satz. Fälle: `tools/emu/plugin_api15_cases.py` (läuft als Gruppe von `remote_cases`). **Am Gerät
nicht geprüft.**

## Pattern-Setter (korg.seq.setPatternValue)

Die Setter sind die aus den [Live-Schreibwegen](2026-11-03-live-schreibwege.md), die das Pattern-Menü beim Drehen ruft.
Jeder legt `r1` unverändert an Objekt + Offset + 4 ab. Aufruf wie im Menü: `r0` das Pattern-Objekt (`0xC06B2798`,
blau `0xC0583FF0`), `r1` das Byte, `r2` 1. Ausnahme MFX TYPE: `r0` ist Objekt + `0x4004`, das Wort dort zeigt auf das
Objekt zurück. Tempo nimmt Zehntel BPM als u16.

| Wert | Byte | Sampler (Hacktribe, rot) | blau |
|---|---|---|---|
| tempo | 34 (u16) | `0xC004A80C` | `0xC00448EC` |
| swing | 36 | `0xC004A594` | `0xC0044674` |
| length | 37 (Takte minus 1) | `0xC004A560` | `0xC0044640` |
| beat | 38 | `0xC004A4F8` | `0xC00445F8` |
| key | 39 | `0xC004A6FC` | `0xC00447DC` |
| scale | 40 | `0xC004A77C` | `0xC004485C` |
| chordSet | 41 | `0xC004A534` | `0xC0044614` |
| level | 42 | `0xC004A698` | `0xC0044778` |
| mfxType | 61 | `0xC0048A64` (Objekt + 0x4004) | `0xC0042CBC` (Objekt + 0x4004) |
| chainTo | 15104 (Pattern + 1) | `0xC004A5B0` | `0xC0044690` |
| chainRepeat | 15106 | `0xC004A5D4` | `0xC00446B4` |
| gateArp | 49 | `0xC004A5F8` | `0xC00446D8` |

Mit jedem Setter über die API gesetzt, steht danach im Block dasselbe Byte, das das Menü für diesen Wert speichert, auf
allen drei Firmwares. Was der Setter nebenbei ändert, ist der Nachzug der Firmware: Length schreibt Step-Daten
(`0x2270` und folgende), Level die Kopie der Klangerzeugung (`0x426E`, blau `0x424E`), MFX TYPE `0x401D`.

## Bereich von MFX TYPE

Seite 5 des Pattern-Menüs (Bildschirm 3) von 0 aus nach unten gedreht, bis der Wert umspringt:

- Hacktribe und rot: 0 bis 39
- blau: 0 bis 31

Die Gerätekarte hatte vorher 0 bis 99. Die Laufzeit klemmt deshalb je Firmware: die Setter-Tabelle trägt für blau eine
Obergrenze von 31.

## Gate Arp

Seite 11 des Pattern-Menüs, Byte 49, 0 bis 49: welches der 50 Muster des Gate Arp spielt.

## Touchpad-X (korg.touchLockX)

Die Firmware rechnet das rohe X einer Touch-Nachricht als `(roh >> 4) * 2` um. Im Master-FX-Modus legt der Handler
(`0xC00454F8`, blau `0xC003F818`) es an +0x1C seines Objekts ab, im Touch-Scale-Modus bekommt die Modusfunktion
(`0xC0060830`, blau `0xC00572E8`) es in `r1`. Mit Sperre bekommt die Firmware den festen Wert (127 wird zu 126), das
Plugin weiter das rohe X des Fingers.

## Tastendruck (korg.pressKey)

Der Druck läuft als Paar aus Drücken und Loslassen durch den Weg der Bedienung. Byte 7 der Nachricht trägt `0xB7` als
Marke, so lässt der Eingangsfilter den Druck zur Firmware durch, ohne ihn den Plugins zu melden.
