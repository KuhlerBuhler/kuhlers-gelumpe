Gemessen 2026-09-17. Beide benutzen dieselbe Zeitkurve, ab Byte 16
deckungsgleich.

| Byte | Zeit |
|---|---|
| 0 bis 8 | unter 30 ms (nicht auflösbar) |
| 16 | 48 ms |
| 24 | 85 ms |
| 32 | 130 ms |
| 48 | 275 ms |
| 64 | 490 ms |
| 80 | 700 ms |
| 96 | 1,1 s |
| 112 | 2,9 s |
| 127 | 5,3 s |
