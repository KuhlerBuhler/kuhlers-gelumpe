BLECHTRIBE 1.5.0 und die App 1.5.0.

**Neu**
- ONE SHOT in SAMPLE EDIT
  - Was: DATA UTILITY > SAMPLE EDIT hat hinter PLAY LEVEL eine Seite ONE SHOT. Mit ON spielt das Sample bis zum Ende durch, auch wenn du das Pad früher loslässt. Auf der roten und mit Hacktribe stellt ON den LOOP START auf den END POINT, wie Korgs eigener One-Shot, OFF stellt ihn auf den START POINT. Auf der blauen gibt es die Seite für jedes `[User]`-Sample.
  - Gut zu wissen: auf der roten gilt die Änderung wie die anderen Seiten von SAMPLE EDIT erst mit WRITE, EXIT ohne WRITE verwirft sie. Hörbar ist sie, sobald du SAMPLE EDIT verlassen hast. Auf die Karte kommt sie mit EXPORT ALL SAMPLE. Die blaue speichert ONE SHOT sofort und merkt sich den alten LOOP START. Nur im Emulator geprüft.

## English

**New**
- ONE SHOT in SAMPLE EDIT
  - What: DATA UTILITY > SAMPLE EDIT has a ONE SHOT page after PLAY LEVEL. With ON the sample plays to its end, even when you let go of the pad early. On the red and with Hacktribe ON puts LOOP START on END POINT, like Korg's own one-shot, OFF puts it on START POINT. On the blue the page is there for every `[User]` sample.
  - Good to know: on the red the change counts only with WRITE, like the other SAMPLE EDIT pages, EXIT without WRITE drops it. You hear it once you have left SAMPLE EDIT. It reaches the card with EXPORT ALL SAMPLE. The blue saves ONE SHOT at once and keeps the old LOOP START. Checked in the emulator only.
