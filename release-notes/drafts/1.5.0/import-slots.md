BLECHTRIBE 1.5.0 und die App 1.5.0.

**Neu**
- IMPORT SAMPLE auf Werks-Slots
  - Was: DATA UTILITY > IMPORT SAMPLE lässt als Ziel jetzt jede Nummer ab 19 zu, mit Hacktribe ab 275, statt nur 501 bis 999. Das Sample ersetzt das Werks-Sample in diesem Slot. Unter der ersten Nummer springt der Wähler auf 999, über 999 wieder auf die erste.
  - Gut zu wissen: wie jedes importierte Sample landet es erst mit EXPORT ALL SAMPLE auf der Karte. Die Slots der Oszillatoren davor bleiben gesperrt, dort lehnt die Firmware den Import ab. Nur die rote Electribe, das IMPORT SAMPLE der blauen füllt nur `[User]`-Plätze.

## English

**New**
- IMPORT SAMPLE onto factory slots
  - What: DATA UTILITY > IMPORT SAMPLE now accepts any destination from 19, from 275 with Hacktribe, instead of only 501 to 999. The sample replaces the factory sample in that slot. Below the first number the selector jumps to 999, above 999 back to the first.
  - Good to know: like any imported sample it reaches the card only with EXPORT ALL SAMPLE. The oscillator slots below stay locked, the firmware refuses the import there. Red Electribe only, the blue's IMPORT SAMPLE fills `[User]` slots only.
