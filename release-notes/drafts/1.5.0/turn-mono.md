BLECHTRIBE 1.5.0 und die App 1.5.0.

**Neu**
- TURN MONO in SAMPLE EDIT
  - Was: ein Stereo-Sample hat in DATA UTILITY > SAMPLE EDIT hinter DECLICK eine Seite TURN MONO. Nach Korgs Frage "Are You Sure ?" wird aus beiden Kanälen einer, (links + rechts) / 2, ohne Übersteuern. Das Sample braucht danach nur noch halb so viel Speicher, START POINT, LOOP START und END POINT bleiben an derselben Stelle.
  - Gut zu wissen: das lässt sich nicht rückgängig machen, EXIT ohne WRITE behält mono. Auf die Karte kommt es mit EXPORT ALL SAMPLE, ohne Export lädt der nächste Start wieder die Stereo-Fassung. Während PLAY läuft, zeigt die Seite "stop PLAY" und ändert nichts. Mono-Samples haben die Seite nicht. Rot und Hacktribe, die blaue legt jedes Sample schon mono ab. Nur im Emulator geprüft.

## English

**New**
- TURN MONO in SAMPLE EDIT
  - What: a stereo sample has a TURN MONO page after DECLICK in DATA UTILITY > SAMPLE EDIT. After Korg's question "Are You Sure ?" both channels become one, (left + right) / 2, without clipping. The sample then takes half the memory, START POINT, LOOP START and END POINT stay in the same place.
  - Good to know: it cannot be undone, EXIT without WRITE keeps mono. It reaches the card with EXPORT ALL SAMPLE, without an export the next start loads the stereo version again. While PLAY runs the page shows "stop PLAY" and changes nothing. Mono samples have no such page. Red and Hacktribe, the blue already stores every sample as mono. Checked in the emulator only.
