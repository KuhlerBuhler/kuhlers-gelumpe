BLECHTRIBE 1.5.0 und die App 1.5.0.

**Neu**
- IMPORT SAMPLE: erst anhören, dann behalten
  - Was: nach DATA UTILITY > IMPORT SAMPLE öffnet sich SAMPLE EDIT mit dem neuen Sample. Alle Pads leuchten, jedes Pad spielt es ab. WRITE behält das Sample und schreibt es wie gewohnt auf die Karte. EXIT verwirft es: es bleibt weder im Sample-Speicher noch auf der Karte etwas davon, und man ist wieder im Dateibrowser für den nächsten Versuch.
  - Gut zu wissen: nur die rote Electribe (Korgs Original und Hacktribe) und nur für die eigenen Plätze 501 bis 999. Ein Import auf einen Werks-Slot läuft wie bisher ohne Vorhören. Ist der Sample-Speicher voll, kommt das Sample wie bisher gleich auf die Karte und wird geladen, sobald ein Part es wählt. Die blaue Electribe hat ein eigenes IMPORT SAMPLE und hört noch nicht vor. Im Emulator geprüft, am Gerät noch nicht.

## English

**New**
- IMPORT SAMPLE: listen first, then keep
  - What: after DATA UTILITY > IMPORT SAMPLE, SAMPLE EDIT opens on the new sample. All pads light up and every pad plays it. WRITE keeps the sample and writes it to the card as usual. EXIT discards it: nothing of it stays in the sample memory or on the card, and you are back in the file browser for the next try.
  - Good to know: red Electribe only (Korg's original and Hacktribe), and only for the user slots 501 to 999. An import to a factory slot works as before, without the preview. When the sample memory is full, the sample goes to the card at once as before and loads as soon as a part picks it. The blue Electribe has its own IMPORT SAMPLE and does not preview yet. Checked in the emulator, not yet on a device.
