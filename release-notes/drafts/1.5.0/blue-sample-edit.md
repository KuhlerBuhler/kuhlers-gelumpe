BLECHTRIBE 1.5.0 und die App 1.5.0.

**Neu**
- IMPORT SAMPLE und SAMPLE EDIT auf der blauen Electribe
  - Was: die blaue holt WAV-Dateien jetzt selbst von der Karte. DATA UTILITY > IMPORT SAMPLE zeigt die Karte wie Korgs Dateibrowser: oben die Ordner, darunter die `.wav`-Dateien, ENTER öffnet einen Ordner, Upper Folder geht zurück. ENTER auf einer WAV, das Rad wählt das Ziel `[User]` 1 bis 64, ENTER importiert. Das Sample landet in der Sample-Datei und spielt sofort, ohne Neustart. DATA UTILITY > SAMPLE EDIT stellt für jedes `[User]`-Sample START POINT, LOOP START, END POINT, SAMPLE TUNE und PLAY LEVEL ein wie auf der roten, dazu neu REVERSE (rückwärts abspielen).
  - Gut zu wissen: die blaue macht aus jeder WAV 16 Bit mono, Stereo wird gemittelt. Punkte und TUNE hörst du ab der nächsten Note, auf die Karte kommen sie mit EXIT oder beim Wechsel auf ein anderes Sample; PLAY LEVEL und REVERSE werden sofort gespeichert. Die App lässt die Einstellungen stehen, wenn sie die Sample-Datei ändert. Den Ordner im Browser merkt sich die blaue bis zum Ausschalten. Nur im Emulator geprüft, ohne Gerätetest an einer blauen.

## English

**New**
- IMPORT SAMPLE and SAMPLE EDIT on the blue Electribe
  - What: the blue now takes WAV files from the card by itself. DATA UTILITY > IMPORT SAMPLE shows the card like Korg's file browser: folders first, then the `.wav` files, ENTER opens a folder, Upper Folder goes back. ENTER on a WAV, the dial picks the target `[User]` 1 to 64, ENTER imports. The sample goes into the sample file and plays right away, no restart needed. DATA UTILITY > SAMPLE EDIT sets START POINT, LOOP START, END POINT, SAMPLE TUNE and PLAY LEVEL for each `[User]` sample like on the red, plus the new REVERSE (play backwards).
  - Good to know: the blue turns every WAV into 16-bit mono, stereo is averaged. You hear points and TUNE from the next note on, they reach the card with EXIT or when you select another sample; PLAY LEVEL and REVERSE are saved at once. The app keeps these settings when it changes the sample file. The blue remembers the browser's folder until you switch it off. Checked in the emulator only, no device test on a blue.
