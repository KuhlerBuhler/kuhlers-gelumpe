### Entwurf release-notes/1.5.0.md (kommt mit dem Versionssprung)

**Behoben**
- DATA UTILITY: der Zähler oben zeigt im Fenster einer Funktion ihre Nummer
  - Was: nach ENTER auf SOFTWARE UPDATE (14) stand oben 13, die Nummer von FACTORY RESET; IMPORT SAMPLE (9) zeigte 8. Auf der blauen zeigte SOFTWARE UPDATE (11) 8. Der Fehler steckt schon in Korgs Firmware.

## English

**Fixed**
- DATA UTILITY: the counter on top shows the function's number in its window
  - What: after ENTER on SOFTWARE UPDATE (14) the top showed 13, the number of FACTORY RESET; IMPORT SAMPLE (9) showed 8. On the blue, SOFTWARE UPDATE (11) showed 8. The bug is in Korg's own firmware.
