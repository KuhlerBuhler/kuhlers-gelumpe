BLECHTRIBE 1.5.0 und die App 1.5.0.

**Neu**
- REVERSE in SAMPLE EDIT auf der roten
  - Was: DATA UTILITY > SAMPLE EDIT hat hinter ONE SHOT eine Seite REVERSE. ON dreht das Sample um, es spielt rückwärts. OFF dreht es zurück, es klingt dann genau wie vorher.
  - Gut zu wissen: START POINT, LOOP START und END POINT bleiben stehen und gelten auf dem umgedrehten Sample, wie auf der blauen. Die Seite wirkt sofort, auf die Karte kommt es mit EXPORT ALL SAMPLE. Rot und Hacktribe. Nur im Emulator geprüft.

## English

**New**
- REVERSE in SAMPLE EDIT on the red
  - What: DATA UTILITY > SAMPLE EDIT has a REVERSE page after ONE SHOT. ON turns the sample round, it plays backwards. OFF turns it back, it then sounds exactly as before.
  - Good to know: START POINT, LOOP START and END POINT stay where they are and count on the reversed sample, as on the blue. The page acts at once, it reaches the card with EXPORT ALL SAMPLE. Red and Hacktribe. Checked in the emulator only.
