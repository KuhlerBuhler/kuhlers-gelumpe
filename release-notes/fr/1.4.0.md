BLECH 1.4.0 et l’application 1.4.0.

**Nouveautés**
- Consulter et écouter un autre pattern pendant la lecture : tourne le bouton pendant la lecture (VIEW: ou NEXT:). Les pads représentent le pattern consulté et utilisent une couleur distincte. Appuie sur un pad en mode PART MUTE pour intégrer immédiatement sa partie au pattern en lecture, sans changer de pattern. Ensuite, ce pad active ou désactive le son de cette partie. Les états muets définis dans l’aperçu accompagnent le pattern lors du changement. SHIFT + PART MUTE bascule les pads entre le pattern consulté et celui en lecture. Rien n’est enregistré dans la banque.
- Patch du firmware : l’application guide la procédure en quelques clics. Choisis d’abord ton appareil (rouge, bleu, Hacktribe rouge ou Hacktribe bleu), puis le résultat souhaité (BLECH, BLECH + Hacktribe ou mise à jour seule). Une case facultative télécharge `hacktribe-2.patch` directement depuis Hacktribe.
- Mise à jour sans l’original : la nouvelle version peut remplacer directement BLECH 1.3.4 à 1.3.7 dans un fichier déjà modifié, y compris un `SYSTEM.VSB` copié auparavant sur la carte. Aucun téléchargement Korg ni `ORIGINAL.BIN` n’est nécessaire.
- Si l’outil refuse un fichier Korg 2.02 de la carte parce qu’il diffère de celui de la mise à jour Korg, l’application télécharge et utilise l’original Korg, sous réserve d’acceptation de sa licence.
- BEAT 8 dans le menu Pattern : chaque pas devient une croche et le pattern dure deux fois plus longtemps, comme à 80 BPM au lieu de 160. L’horloge MIDI et la synchronisation restent au tempo réel. Disponible sur les modèles rouge et bleu.
- Global > TOUCH SCALE RANGE accepte 0 : X sur le pavé tactile joue alors la tonique du pattern où que tu appuies. Disponible sur les modèles rouge et bleu.
- Un sample stéréo n’occupe plus que son propre pad ; le pad voisin joue son propre sample. Désactive ce comportement dans BLECH > FEATURES > STEREO 1 PAD. Modèle rouge uniquement.
- BLECH > FEATURES > LAST PATTERN : sur OFF, l’Electribe démarre toujours avec le pattern 001.
- Le rétroéclairage prend ta couleur dès l’allumage, sans attendre la fin de l’image de démarrage. Sur le modèle bleu, la couleur apparaît pendant cette image.
- Animation de chargement personnalisée : la section Design propose 100 images, un éditeur et l’import GIF à côté de l’image de démarrage. La barre avance selon les octets lus et ne reste plus immobile sur un gros sample.
- Nouvelle organisation des menus : SYNC GROUP suit CHAIN REPEAT ; PLUGIN RUNTIME devient la dernière page de GLOBAL. DATA UTILITY propose EXPORT ALL CUSTOMIZATIONS, EXPORT ALL PLUGINS, EXPORT ALL EFFECTS (modèle rouge uniquement) et SET INIT PATTERN.
- BLECH > PLUGINS > MANAGE PLUGINS remplace PLUGIN EDIT : liste de 64 plugins au maximum, activables avec le bouton. Chaque plugin propose DESCRIPTION, OFF (désactivation en conservant le fichier) et REMOVE (suppression du fichier ; sur le modèle bleu, il reste sur la carte).
- Les désactivations restent enregistrées avec jusqu’à 64 plugins sur la carte, contre 16 auparavant. Le format des réglages change : revenir à la version 1.3.7 fait perdre les réglages enregistrés avec la 1.4.0.
- Electribe bleue : au premier démarrage, BLECH propose de copier `KORG/electribe/` vers `KORG/blechtribe/`. MENU copie, EXIT démarre sans copie.
- Doom : maintenir SHIFT + TAP au démarrage sans les fichiers Doom lance désormais l’Electribe normalement au lieu de rester bloqué sur DOOM ERROR.
- La section Secours couvre de nouveaux cas : Error Invalid File, Error No File, appareil introuvable, anciens patterns après un import ou un export, vérification complète qui reste rouge.
- Le bouton supérieur affiche « Déconnecter » lorsque l’Electribe est connectée. Son utilisation désactive la connexion automatique ; une nouvelle connexion la réactive.

**Corrections**
- Un fichier Hacktribe contenant déjà BLECH 1.3.3 ne pouvait pas être modifié (« different bytes at 0x180100 »). L’outil explique aussi plus clairement les problèmes d’un fichier inconnu.
- Les effets du catalogue étaient trop forts ; leurs niveaux correspondent désormais à ceux de Korg. Les effets intégrés par BLECH reçoivent les nouvelles valeurs à la mise à jour. Ceux copiés depuis le catalogue doivent être repris dans celui-ci.
- EXIT maintenu + pad réinitialise la partie du pad dans tous les modes sauf SEQUENCER et STEP JUMP. Auparavant, seul TRIGGER le faisait ; les autres modes modifiaient la partie sélectionnée.
- La dernière étape de modification du firmware ne demande plus de copier l’ancien dossier à la main : l’Electribe le propose au premier démarrage.
- Plus de message rouge à la connexion lorsque l’émulateur utilise le firmware Korg d’origine.
- L’émulateur pouvait s’arrêter avec une erreur AM180xMMSDCardController.cpp pendant la copie du dossier au premier démarrage.

**Nouveautés pour le développement**
- Temporisateurs de plugins avec `korg.after`, `korg.every`, `korg.afterSteps` et `korg.cancel` (API 11). Ils fonctionnent aussi lorsque l’application du plugin est fermée.
- `korg.padHold(1)` empêche le firmware de recevoir les appuis sur les pads ; le plugin continue de les recevoir (API 12).
- L’éditeur complète et explique l’arbre des réglages (`korg.menu.`, `korg.system.`) et les temporisateurs. Nouvel exemple dans le catalogue : Takt-Blinker.
- La forme `korg.millis` sans parenthèses disparaît ; utilise `korg.millis()`. Le compilateur signale les parenthèses manquantes.
- Commande à distance par USB : boutons, potentiomètres, pads et pavé tactile pilotables depuis l’ordinateur, plus un mode de test à écran et LED éteints. Cette version refuse l’activation à distance de ce mode sur une vraie Electribe : il fonctionne uniquement dans l’émulateur. La commande USB à distance ne fonctionne pas encore sur le modèle bleu.
- Auto-hébergement : les versions publient une image de conteneur que `docker compose pull` récupère. Un contrôle de santé indique l’état du conteneur.

**Corrections pour le développement**
- Dans l’émulateur, les pads ne s’allument que sur commande du firmware. Auparavant, tout pad pressé s’allumait, même avec `korg.padHold`.
