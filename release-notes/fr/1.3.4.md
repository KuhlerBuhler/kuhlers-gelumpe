BLECH 1.3.4 et l’application 1.3.4.

**Nouveautés**
- BLECH sur l’Electribe bleue, avec ou sans Hacktribe. Sans le patch Hacktribe, le résultat est BLECHTRIBE seul.
- Après acceptation de la licence Korg, l’application télécharge directement le firmware Korg rouge ou bleu. Dans le navigateur, la case ouvre le lien Korg. L’archive ZIP Korg peut aussi être déposée dans le champ.
- Le firmware rouge Korg avec le patch Hacktribe peut être préparé pour l’appareil rouge ou bleu. Pour le bleu, le fichier reçoit l’en-tête permettant à sa procédure de mise à jour Korg de l’accepter.
- Discord : les personnes en ligne traversent toute la largeur sous forme de Blechy et dansent chacune à leur rythme. La liste se rafraîchit chaque minute ; les salons vocaux n’y apparaissent plus.
- Samples : la page `e2sSample.all` accepte le glisser-déposer et la sélection de fichiers.

**Corrections**
- Electribe bleue : BLECH utilise `KORG/blechtribe`, crée les dossiers manquants et enregistre à nouveau les réglages. Copie une fois `KORG/electribe` vers `KORG/blechtribe` pour retrouver tes données.
- Un firmware bleu modifié était pris pour Hacktribe. L’outil demande désormais le fichier Korg intact de l’archive ZIP et affiche sa somme de contrôle.
- `BLECH.patch` accepte les firmwares Korg 2.02 rouge et bleu ainsi que Hacktribe ; chaque patch apparaît une seule fois dans la liste.
- L’option affiche la version complète et les cases cochées affichent leur coche.
- Sur les ordinateurs lents, l’arrière-plan animé s’immobilise s’il ne suit plus. Il se met en pause lorsqu’une autre fenêtre passe devant.
