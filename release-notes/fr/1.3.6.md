BLECH 1.3.6 et l’application 1.3.6.

**Nouveautés**
- En mode « Vrai appareil », l’application se connecte automatiquement dès qu’une Electribe est branchée, puis à chaque reconnexion. Ce comportement se désactive dans les réglages avec « Se connecter automatiquement ».
- Diagnostic MIDI dans les réglages : liste les ports visibles et ceux reconnus comme l’Electribe. « Copier » place le rapport dans le presse-papiers pour le partager sur Discord si l’appareil reste introuvable.
- L’outil de modification du firmware peut faire apparaître l’appareil comme « Electribe 3 » sur l’ordinateur. L’option est désactivée par défaut. Il faut ensuite réassocier les commandes de la station audio liées à l’ancien nom du port.
- Blechy marche désormais comme sur la page Discord et regarde dans sa direction de déplacement.
- La page de Blechy reste sombre même sans DISPLAY INVERT, pour éviter les traînées pendant sa marche.
- La police de l’écran comprend ä, ö et ü ; les plugins peuvent aussi les utiliser.

**Modifications**
- Les derniers textes allemands de l’appareil passent en anglais : « Line » sur l’écran d’erreur d’un plugin, « Paused » et « no file » dans le lecteur GIF, « Seconds » dans le modèle de minuterie. Blechy et la barre de chargement restent en allemand.
- L’outil affiche les noms des patches dans ta langue.

**Corrections**
- Discord : tous les Blechy démarraient sur le bord gauche si la page se chargeait en arrière-plan.
