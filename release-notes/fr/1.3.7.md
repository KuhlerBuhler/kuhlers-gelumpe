BLECH 1.3.7 et l’application 1.3.7.

**Nouveautés**
- L’Electribe démarre avec le dernier pattern sélectionné. Maintiens EXIT à l’allumage pour démarrer avec 001 comme auparavant.
- BLECH > FEATURES > INIT PATTERN permet de choisir le modèle copié par INITIALIZE PATTERN dans DATA UTILITY. FACTORY et EXIT à l’allumage conservent le modèle Korg.
- Ces deux fonctions sont aussi disponibles sur l’Electribe bleue.
- BLECH > VERSION affiche la version de BLECH utilisée par l’appareil.
- L’application affiche les notes des versions précédentes, même hors ligne.
- Le diagnostic MIDI identifie le pilote Korg sous Windows lorsqu’il bloque la communication. Ce pilote empêche les réponses de l’Electribe d’arriver ; le pilote Windows fonctionne.
- La vérification complète du firmware est plus rapide.

**Corrections**
- Un plugin désactivé dans PLUGIN EDIT reste désactivé après un redémarrage, même avec beaucoup de plugins sur la carte. La sauvegarde pouvait confondre les listes de plugins désactivés et autorisés ; une liste pleine (16 entrées) empêchait d’enregistrer la désactivation.
- La vérification complète échouait (menu, changement de pattern, TAP Motion, assistant de notes, génération aléatoire) si des patterns étaient enregistrés dans l’émulateur, par exemple après un import. Les vérifications utilisent désormais une mémoire flash vide et préservent tes patterns dans l’émulateur.
- Après une mise à jour de l’application, les résultats de vérification de l’ancienne version pouvaient rester en cache.
- Sous Windows, l’appareil est reconnu même si les ports portent le nom de leur prise.

**Nouveautés pour le développement**
- `korg.get` et `korg.set` accèdent aux réglages par un arbre d’objets ; la première valeur disponible est la luminosité de l’écran (API 10).
- Console : l’essai d’un script démarre l’émulateur derrière l’Electribe connectée sans la déconnecter.
- Auto-hébergement : l’éditeur fonctionne dans un conteneur Docker et derrière un proxy inverse, avec la carte dans `./SD`.

**Corrections pour le développement**
- `korg.store` enregistre aussi lorsque le menu BLECH est ouvert.
