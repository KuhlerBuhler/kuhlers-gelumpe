BLECHTRIBE 1.4.5 und die App 1.4.5.

**Neu**
- Plugin Momentary Mute im Katalog
  - Was: PART MUTE gilt nur, solange du die Taste hältst, wie bei der Korg ESX.
  - So geht's: PART MUTE halten und Pads drücken schaltet Parts stumm oder an. Lässt du PART MUTE los, spielen die Pads wieder wie im Modus TRIGGER.
  - An und aus: Menü -> BLECH -> MOMENT MUTE, 1 an, 0 aus. SHIFT + PART MUTE bleibt, wie die Firmware es macht.
- Plugin BMP Viewer im Katalog (unter TOOLS)
  - Was: zeigt mehrere Bilder von der Karte nacheinander am Display.
  - So geht's: in der App unter Design -> BMP Viewer deine BMPs (oder andere Bilder) wählen, die App packt sie in eine Datei `GIF00.E2G` bis `GIF99.E2G`, die kommt nach `KORG/blechtribe/Gif/`. Im BMP Viewer blättern ◄ PART und PART ► durch die Bilder, der Encoder wählt die Datei, TAP zeigt oder versteckt die Bildnummer.
- Plugin Gate Hold im Katalog
  - Was: im Touchpad-Modus Gate Arp bleibt die Note dort, wo dein Finger zuerst aufsetzt.
  - So geht's: GATE ARP drücken, das Touchpad berühren und den Finger zur Seite schieben: X wählt jetzt den Gate-Arp-Rhythmus, die Note bleibt. Finger weg holt den Rhythmus des Patterns zurück.
  - An und aus: Menü -> BLECH -> GATE HOLD, 1 an, 0 aus.
- Plugin Step Copy im Katalog
  - Was: kopiert die Steps eines Takts in einen anderen Takt, so musst du denselben Takt nicht noch einmal einspielen.
  - So geht's: unter Menü -> BLECH den Quelltakt bei STEP COPY FROM und den Zieltakt bei STEP COPY TO wählen (0 heißt alle Takte danach), dann STEP COPY auf 1 (gewählter Part) oder 2 (alle Parts). Kopiert wird, sobald das Rad kurz ruht.
  - Gut zu wissen: die Motion Sequence und die Werte des Parts kopiert es nicht mit. Gespeichert ist das Pattern erst nach WRITE.
- Plugin PLAY-Takt im Katalog
  - Was: solange der Sequencer läuft, blinkt die PLAY-LED im Tempo des Patterns, bei STOP und Pause leuchtet sie ruhig.
- Keypads
  - Was: der KEY des Patterns über die Pads, wie TRANSPOSE bei den alten Electribes.
  - So geht's: KEYBOARD halten und ein Pad drücken. Pad 1 bis 12 sind C bis B, Pad 13 bis 16 tun nichts. KEYBOARD kurz allein gedrückt schaltet wie immer den Modus.
  - An und aus: Menü -> BLECH -> FEATURES -> KEY PADS, standardmäßig an.
- Filter Toggle
  - Was: schaltet das Filter des gewählten Parts aus und wieder an.
  - So geht's: SHIFT + LPF, HPF oder BPF schaltet das Filter aus, dieselbe Kombination wieder an, mit dem Typ, den die Taste zuletzt hatte. Jeder Part merkt sich seine Typen.
  - An und aus: Menü -> BLECH -> FEATURES -> FILTER TOGGLE, standardmäßig an.
- AUTO SAVE
  - Was: verlässt du GLOBAL PARAMETERS oder das Menü BLECH und hast dort etwas geändert, speichert BLECHTRIBE das wie WRITE. Ohne Änderung wird nichts geschrieben.
  - Gut zu wissen: Patterns speicherst du weiter selbst mit WRITE.
  - An und aus: Menü -> BLECH -> FEATURES -> AUTO SAVE, standardmäßig an.
- Hacktribe-Oszillatoren auf Korgs Firmware der roten
  - Was: auf den leeren Plätzen 422 bis 497 liegen jetzt 76 Oszillatoren aus Hacktribe: DUAL, OCT, CHIP und RING, dazu X und VPM in Stufen.
  - So geht's: am OSC-Regler hinter den Werks-Samples. Deine eigenen Samples ab Platz 501 bleiben, wo sie sind.
  - Mit EXIT beim Einschalten bleiben die Plätze leer wie in der Firmware.
- ORIG im BLECH-Menü
  - Was: die Seiten von BLECH zeigen jetzt wie GLOBAL PARAMETERS das Schildchen ORIG, solange der Wert der gespeicherte ist.
  - So geht's: du änderst einen Wert, das Schildchen verschwindet, drehst du zurück, kommt es wieder. Nach WRITE gilt es für den neuen Wert. Ohne Einstellungsdatei sind die Standardwerte die gespeicherten.
- Pattern-Vorschau: blinkende Pads
  - Was: drehst du beim Spielen am Rad, zeigt das Display ein anderes Pattern (`VIEW:` oder `NEXT:`), und das laufende spielt weiter. Im Modus PART MUTE blinken jetzt die Pads der Parts, die im angesehenen Pattern an sind. So siehst du, welche Parts du von dort ins laufende Pattern holen kannst.
  - So geht's: ein Druck auf ein blinkendes Pad holt den Part ins laufende Pattern, ohne Patternwechsel, das Pad leuchtet dann fest. Ein Part, der im angesehenen Pattern stumm ist, bleibt dunkel, ein Druck holt ihn trotzdem.
  - Neu mit SHIFT + PART MUTE (die Pads zeigen dann das laufende Pattern): die geholten Parts bleiben gemerkt und blinken dort. Ein Druck auf so ein Pad gibt dem laufenden Pattern seinen eigenen Part zurück.
- Blechy statt Rettung
  - Was: die Seite Rettung heißt jetzt Blechy. Statt Schritt für Schritt Fragen zu beantworten, schreibst du in ein Feld, was los ist, und Blechy zeigt die passenden Fälle, in allen elf Sprachen und auch mit Tippfehlern.
  - Gut zu wissen: alles bleibt auf deinem Rechner. Bei jeder Fehlermeldung der App kannst du Blechy fragen, und Blechy erklärt, was ein roter Test im Patcher bedeutet.
- Blechy prüft die SD-Karte
  - Was: Blechy sagt dir, was an Name oder Ordner deiner `SYSTEM.VSB` nicht stimmt, und legt die Datei auf Wunsch an die richtige Stelle.
  - Gut zu wissen: dabei wird nichts gelöscht.
- Zurück zu Korgs Original
  - Was: ein neuer Fall bei Blechy mit Anleitung, auch für die blaue Electribe, mit und ohne Hacktribe darauf.
  - Gut zu wissen: für eine blaue mit Hacktribe macht die App die passende Datei aus deiner eigenen Korg-Datei, sie bleibt auf deinem Rechner.
- Blechy hilft bei der App
  - Was: Blechy beantwortet jetzt auch Fragen zur Bedienung der App: BLECHTRIBE installieren, Hacktribe oder nicht, Plugins und Spiele wie Tetris, eigene Effekte, Emulator, eigene Samples, Updates, Einstellungen speichern und das Startbild.
  - So geht's: die ersten Themen auf der Startseite folgen dem, was im Discord am häufigsten gefragt wird. Meldet die App einen Fehler, öffnet Blechy das Thema der Seite, etwa "Der Emulator läuft nicht" bei der Emulator-Hilfe.
  - Gut zu wissen: auf der Startseite stehen Zurück und Von vorn nicht mehr. Auf der Discord-Seite zeigt ein Blechy beim Darüberfahren keinen Namen mehr.
- Warnung vor Hacktribe im Patcher
  - Was: setzt du den Haken für Hacktribe, sagt die App, dass Hacktribe deine Samples wegnehmen kann, und du bestätigst mit einem Häkchen, dass du die Karte gesichert hast.
  - Gut zu wissen: dazu hat Blechy den Fall "Ich hab aus Versehen Hacktribe installiert".
- Patcher-Assistent fragt nach der Firmware
  - Was: nach der Farbe deines Geräts fragt der Assistent jetzt, welche Firmware schon darauf läuft. Danach bietet er nur an, was von dort aus geht, auch den Weg zurück zu Korgs Original.
- Korgs Firmware über Weiter
  - Was: Korgs Firmware holt jetzt Weiter, ohne eigenen Knopf davor. Hast du Korgs Lizenz bestätigt und keine eigene Datei hineingelegt, lädt Weiter sie von Korg. Die App lädt sie selbst, im Browser startet der Download, und du legst die Datei dann in das Feld.
  - Gut zu wissen: eine eigene Datei ersetzt die App nie.
- Speichern direkt auf die SD-Karte (App)
  - Was: im letzten Schritt sucht die App eine eingesteckte Karte mit dem passenden `KORG`-Ordner, zeigt den ganzen Pfad und speichert mit Speichern gleich dorthin, statt in Downloads.
  - Gut zu wissen: fehlt der Ordner `System`, legt sie ihn an. Der Speichern-Dialog bleibt als zweite Möglichkeit.
- Eigene Patches im Patcher
  - Was: die Fläche für den eigenen Patch nimmt jetzt jede Patch-Datei an, nicht nur die von GELUMPE.
  - So geht's: die Datei im Patcher auf die Fläche für den eigenen Patch ziehen.
- Ordner auf der Karte
  - Was: beim Start legt BLECHTRIBE `KORG/blechtribe/` und die Unterordner an, die dort fehlen (rot: Plugin, Presets, Gif, Doom, Sample, System; blau: Plugin, Gif, System).

Der Test hat die Startphase bis zu 20 ms zu spät beendet und sah dadurch, je nach Startzeit deiner Datei, Code von BLECHTRIBE, der erst nach dem Hauptbildschirm läuft. Die Firmware war nicht betroffen.
- Effekte aus `e2sFx.all` wirken jetzt nach dem Einschalten wirklich, vorher lief weiter der Originaleffekt.
- EXPORT ALL EFFECTS legt `e2sFx.all` an, wenn die Datei auf der Karte fehlt.
- Mit einer SD-Karte, die nicht antwortet, blieb der Start beim Startbild von BLECHTRIBE hängen. Jetzt startet die Electribe weiter wie die Firmware ohne BLECHTRIBE.
- Startet das Gerät ohne Karte und steckst du sie erst später ein, wirkten PATTERN CONFIRM, TAP MOTION, NOTE ASSIST und das Würfeln erst nach dem ersten Speichern. Jetzt gelten sie, sobald die Karte steckt, und eine geänderte Einstellung wirkt sofort.
- Schnelles Blättern durch die Patterns in der Vorschau hängt nicht mehr hinterher, beim Abspielen und auch gestoppt mit ungespeicherten Änderungen.

- Windows: fehlt die WebView2 Runtime, sagt die App das jetzt und öffnet die Download-Seite von Microsoft, statt nur einen Fehlercode zu zeigen.
- Auf schmalen Bildschirmen springt die Seite beim Öffnen und Schließen des Sprachmenüs nicht mehr nach oben, und das Menü bleibt ganz im Bild.

**Neu für Entwickler**
- Plugin-API 12 auf 25.
- Regler halten (API 13)
  - `korg.knobHold(index, an)`: hält den Regler `index` (0 bis 10) von der Firmware fern, `an` 1 hält, 0 gibt frei. Das Plugin bekommt `knob` weiter. Keine Rückgabe.
  - `korg.knob(index, wert)`: gibt der Firmware für den Regler den Wert `wert` (0 bis 255), als hätte der Regler ihn gesendet. Keine Rückgabe.
- Tasten (API 14 und 15)
  - `korg.passKeys(taste, an)`: lässt bei offener App die Taste `taste` (0 bis 33) trotzdem zur Firmware durch. Keine Rückgabe.
  - `korg.keyHold(taste, an)`: hält die Taste von der Firmware fern, auch ohne offene App. Das Plugin bekommt `buttonPress` und `buttonRelease` weiter. Keine Rückgabe.
  - `korg.pressKey(taste)`: drückt die Taste kurz für die Firmware. Keine Rückgabe.
- Jedes Plugin hält seine Eingaben für sich (API 19)
  - Was ein Plugin von der Firmware fernhält (Tasten, Regler, Pads), merkt sich die Laufzeit für jedes Plugin einzeln. Die Firmware bekommt eine Eingabe erst wieder, wenn kein laufendes Plugin sie mehr hält. Gibt ein Plugin eine Taste frei, ändert das nichts an den anderen.
  - `korg.keyMask(low, high)`: setzt in einem Aufruf alle Tasten, die dieses Plugin fernhält. Die Electribe hat 34 Tasten ohne die Pads, Nummer 0 bis 33 wie `korg.key.PLAY`. Eine Zahl hat nur 32 Bits, deshalb zwei: in `low` steht Bit n für Taste n (0 bis 31), in `high` Bit 0 und 1 für die Tasten 32 und 33. Keine Rückgabe.
- Touchpad
  - `korg.touchLockX(x)` (API 15): hält das X, das die Firmware sieht, auf `x` (0 bis 127), -1 lässt los. Das geht nur für X: Y bleibt immer das des Fingers, ein Halten von Y gibt es nicht. Das Plugin bekommt in `touch` weiter das echte X. Keine Rückgabe.
  - X und Y setzen geht so: `korg.touch(x, y)` (API 25) legt einen Finger auf das Touchpad, mit Rohwerten 0 bis 1023 für beide wie die des Panels, jeder weitere Aufruf bewegt ihn, `x` = -1 hebt ihn ab. `korg.pattern.current.mfxPadX` und `mfxPadY` (API 24, 0 bis 127) setzen den Touchpad-Wert des Modus Master FX im Pattern und senden den MIDI-CC wie das Touchpad.
- Bedienen wie ein Finger (API 25)
  - `korg.keyDown(taste)` und `korg.keyUp(taste)`, `korg.padDown(pad, velocity)` und `korg.padUp(pad)`, `korg.encoder(index, delta)` und `korg.touch(x, y)` geben der Firmware dieselben Nachrichten wie das Panel, an Haltern, offener App und anderen Plugins vorbei. Alle ohne Rückgabe.
- Werte des laufenden Patterns (API 21)
  - `korg.pattern.current.<wert>` ist eine Gruppe von Eigenschaften, kein Objekt für eine Variable: jeder Wert ist eine ganze Zahl, lesbar und setzbar. Die Werte: `tempo` (Zehntel BPM), `swing`, `length`, `beat`, `key`, `scale`, `chordSet`, `level`, `mfxType`, `chainTo`, `chainRepeat`, `gateArp`, `syncGroup`, ab API 24 auch `alternate1314`, `alternate1516`, `mfxHold`, `mfxPadX`, `mfxPadY`.
  - `korg.current.<wert>` konnte man schon lesen, seit API 15 auch setzen. `korg.pattern.current` (API 21) ist dieselbe Gruppe unter neuem Namen, als Aufruf `korg.seq.setPatternValue(wert, x)`. Setzen geht über die Funktion der Firmware, die auch das Pattern-Menü nimmt.
- Werte der Parts setzen (API 14 bis 24)
  - `korg.parts[i].<wert>` (Part `i` 0 bis 15, jeder Wert eine ganze Zahl) ist jetzt auch setzbar, als Aufruf `korg.seq.setPartValue(part, wert, x)`. Es geht über die Funktion der Firmware, die auch die Regler nehmen.
  - Seit API 24 sendet ein Setzen den MIDI-CC wie der Regler und öffnet dessen Fenster. `korg.display.popups` (0 oder 1) hält das Fenster für dieses Plugin zu.
- Steps lesen und schreiben
  - `korg.seq.getOn(part, step)`, `korg.seq.getGate(part, step)`, `korg.seq.getVelocity(part, step)` und `korg.seq.getNote(part, step, platz)` geben eine ganze Zahl zurück, `getNote` -1 für einen leeren Platz (API 22).
  - `korg.read.patternBytes(feld, pattern, offset)` kopiert Bytes eines Patterns in ein Feld und gibt ihre Zahl zurück, `korg.seq.writeSteps(feld, part, erster)` schreibt ganze Steps und gibt die Zahl der Steps zurück (API 14).
- Angesehenes und nächstes Pattern (API 18)
  - `korg.viewedPattern`: ganze Zahl 0 bis 249, nur lesen. Das Pattern, das das Display zeigt, beim Blättern das angesehene.
  - `korg.nextPattern`: ganze Zahl 0 bis 249, -1 wenn keins wartet, nur lesen. Das nächste Pattern, das der Patternwechsel bestätigt hat.
  - Als Aufruf: `korg.read.viewedPattern()` und `korg.read.nextPattern()`.
- Globals (API 20)
  - `korg.global.*`: ein Wert für jede der 19 Seiten von GLOBAL PARAMETERS, etwa `korg.global.midiChannel` (0 bis 15) oder `korg.global.metronome` (0 bis 4). Jeder ist eine ganze Zahl, lesbar und setzbar, und wirkt sofort wie im Menü.
- Menü BLECH (API 17)
  - `korg.menu.blech.*`: jede Seite von CUSTOMIZATION und FEATURES, dazu SET INIT PATTERN, als ganze Zahl zum Lesen und Setzen.
  - `korg.menu.blech.write()` schreibt diese Einstellungen auf die Karte wie WRITE. Keine Rückgabe.

## English

BLECHTRIBE 1.4.5 and the app 1.4.5.

**New**
- Momentary Mute plugin in the catalog
  - What: PART MUTE only works while you hold the key, like on the Korg ESX.
  - How: hold PART MUTE and press pads to mute or unmute parts. Let go of PART MUTE and the pads play as in TRIGGER mode again.
  - On and off: Menu -> BLECH -> MOMENT MUTE, 1 on, 0 off. SHIFT + PART MUTE stays as the firmware does it.
- BMP Viewer plugin in the catalog (under TOOLS)
  - What: shows several pictures from the card one after another on the display.
  - How: in the app under Design -> BMP Viewer pick your BMPs (or other pictures), the app packs them into one file `GIF00.E2G` to `GIF99.E2G`, which goes into `KORG/blechtribe/Gif/`. In the BMP Viewer ◄ PART and PART ► page through the pictures, the encoder picks the file, TAP shows or hides the picture number.
- Gate Hold plugin in the catalog
  - What: in the touch pad mode Gate Arp the note stays where your finger first lands.
  - How: press GATE ARP, touch the pad and slide your finger sideways: X now picks the Gate Arp rhythm, the note stays. Lifting the finger brings back the pattern's rhythm.
  - On and off: Menu -> BLECH -> GATE HOLD, 1 on, 0 off.
- Step Copy plugin in the catalog
  - What: copies the steps of one bar into another bar, so you do not have to play the same bar in again.
  - How: under Menu -> BLECH pick the source bar at STEP COPY FROM and the target bar at STEP COPY TO (0 means every bar after it), then set STEP COPY to 1 (selected part) or 2 (all parts). It copies once the dial rests for a moment.
  - Good to know: it does not copy the motion sequence or the part's values. The pattern is saved only after WRITE.
- PLAY-Takt plugin in the catalog
  - What: while the sequencer plays, the PLAY LED blinks in the tempo of the pattern, on STOP and pause it stays lit.
- Keypads
  - What: set the pattern's KEY with the pads, like TRANSPOSE on the old Electribes.
  - How: hold KEYBOARD and press a pad. Pads 1 to 12 are C to B, pads 13 to 16 do nothing. KEYBOARD pressed briefly on its own switches the mode as always.
  - On and off: Menu -> BLECH -> FEATURES -> KEY PADS, on by default.
- Filter Toggle
  - What: turns the filter of the selected part off and on again.
  - How: SHIFT + LPF, HPF or BPF turns the filter off, the same combination turns it back on with the type that key had last. Every part keeps its own types.
  - On and off: Menu -> BLECH -> FEATURES -> FILTER TOGGLE, on by default.
- AUTO SAVE
  - What: when you leave GLOBAL PARAMETERS or the BLECH menu after changing something there, BLECHTRIBE saves it like WRITE. Without a change nothing is written.
  - Good to know: patterns you still save yourself with WRITE.
  - On and off: Menu -> BLECH -> FEATURES -> AUTO SAVE, on by default.
- Hacktribe oscillators on Korg's firmware for the red
  - What: the empty slots 422 to 497 now hold 76 oscillators from Hacktribe: DUAL, OCT, CHIP and RING, plus X and VPM in steps.
  - How: on the OSC knob after the factory samples. Your own samples from slot 501 stay where they are.
  - With EXIT held at power-on the slots stay empty as in the firmware.
- ORIG in the BLECH menu
  - What: the pages of BLECH now show the ORIG badge like GLOBAL PARAMETERS does, while the value is the stored one.
  - How: change a value and the badge goes, turn it back and it returns. After WRITE it belongs to the new value. Without a settings file the defaults are the stored ones.
- Pattern preview: blinking pads
  - What: when you turn the dial while playing, the display shows another pattern (`VIEW:` or `NEXT:`) and the playing one keeps running. In PART MUTE mode the pads of the parts that are on in the viewed pattern now blink. That shows you which parts you can bring from there into the playing pattern.
  - How: a press on a blinking pad brings that part into the playing pattern, without a pattern change, and the pad then stays lit. A part that is muted in the viewed pattern stays dark, a press brings it in anyway.
  - New with SHIFT + PART MUTE (the pads then show the playing pattern): the parts you brought in stay marked and blink there. A press on such a pad gives the playing pattern its own part back.
- Blechy instead of Rescue
  - What: the Rescue page is now called Blechy. Instead of answering questions step by step, you type what is wrong, and Blechy shows the cases that fit, in all eleven languages, typos included.
  - Good to know: nothing leaves your computer. You can ask Blechy from any error message of the app, and Blechy explains what a red test in the patcher means.
- Blechy checks the SD card
  - What: Blechy tells you what is wrong with the name or folder of your `SYSTEM.VSB` and moves the file into place if you want.
  - Good to know: nothing is deleted.
- Back to Korg's original
  - What: a new case in Blechy with a tutorial, also for the blue Electribe, with and without Hacktribe on it.
  - Good to know: for a blue with Hacktribe the app makes the matching file from your own Korg file, which stays on your computer.
- Blechy helps with the app
  - What: Blechy now also answers questions about using the app: installing BLECHTRIBE, Hacktribe or not, plugins and games like Tetris, your own effects, the emulator, your own samples, updates, saving settings and the start screen.
  - How: the first topics on the start page follow what is asked most on the Discord server. When the app reports an error, Blechy opens the topic of that page, for example "The emulator does not run" at the emulator help.
  - Good to know: the start page no longer shows Back and Start over. On the Discord page a Blechy no longer shows a name when you hover it.
- Hacktribe warning in the patcher
  - What: when you tick Hacktribe, the app says that Hacktribe can take your samples away, and you confirm with a tick that you backed up the card.
  - Good to know: Blechy has a case for it, "I installed Hacktribe by accident".
- The patcher wizard asks for the firmware
  - What: after the colour of your device the wizard now asks which firmware already runs on it. Then it offers only what works from there, including the way back to Korg's original.
- Korg's firmware through Next
  - What: Next now fetches Korg's firmware, without a separate button first. Once you have accepted Korg's licence and put no file of your own in, Next loads it from Korg. The app loads it itself, in the browser the download starts and you then drop the file into the field.
  - Good to know: the app never replaces a file of your own.
- Save straight onto the SD card (app)
  - What: in the last step the app looks for an inserted card with the matching `KORG` folder, shows the full path and saves there with Save, instead of into Downloads.
  - Good to know: if the `System` folder is missing, it creates it. The save dialog stays as the second way.
- Your own patches in the patcher
  - What: the drop zone for your own patch now takes any patch file, not only GELUMPE's.
  - How: drag the file onto the drop zone for your own patch in the patcher.
- Folders on the card
  - What: at start BLECHTRIBE creates `KORG/blechtribe/` and the subfolders missing there (red: Plugin, Presets, Gif, Doom, Sample, System; blue: Plugin, Gif, System).
  - Good to know: what is already there stays as it is. With EXIT held at power-on none of this happens.

**Changed**
- BLECH -> PLUGINS
  - ENTER on PLUGINS opens the plugin list right away, without the MANAGE PLUGINS page in between.
  - The list looks like DATA UTILITY's file browser and the dial scrolls through it. A page with two lines means the plugin runs, an empty page means it is off.
  - Open a plugin with ENTER to see its pages. The first one is called Active, there you set it to ON or OFF with the VALUE knob. The other pages, such as the one for deleting, stay.
- SPLASH IMPORT
  - Lists every `.bmp` file in `KORG/blechtribe/`, renamed ones too, instead of reading only `splash.bmp`. You pick one with the dial.
- BLECH -> VERSION
  - Now also shows after the firmware whether the effects from `e2sFx.all` were loaded.
- Features page
  - Every card now has a picture, also those that had none before.
- Emulator
  - The display lights up in the colour the firmware sets for its light.
  - Short LED changes reach the page too, such as blinking pads.
- Changelogs
  - The version you have installed, and the newer one the update button fetches, no longer show downloads.

**Fixed**
- The full check in the patcher wrongly reported "Start phase unchanged" for some users, also with 1.4.2. The check ended the start phase up to 20 ms too late, and depending on the start time of your file it saw BLECHTRIBE code that only runs after the main screen. The firmware was not affected.
- Effects from `e2sFx.all` now really take effect after power-on, before the original effect kept playing.
- EXPORT ALL EFFECTS creates `e2sFx.all` when the file is missing on the card.
- With an SD card that does not answer, the start hung at BLECHTRIBE's splash screen. Now the Electribe goes on starting like the firmware without BLECHTRIBE.
- When the device starts without a card and you insert it later, PATTERN CONFIRM, TAP MOTION, NOTE ASSIST and the dice only worked after the first save. They now work as soon as the card is in, and a changed setting acts at once.
- Turning fast through the patterns in the preview no longer lags behind, while playing and also stopped with unsaved changes.
- The patcher asks for the device only once, not in the wizard and then again at the file step.
- Windows: when the WebView2 Runtime is missing, the app now says so and opens Microsoft's download page, instead of showing only an error code.
- On narrow screens the page no longer jumps to the top when you open and close the language menu, and the menu stays fully on screen.
- The title of the Changelogs page had a "!" at the end when there was a new release.
- Baukasten: the export of `e2sFx.all` depended on the firmware in the emulator. With Korg's original there and Hacktribe on the Electribe, the Electribe refused the file silently. Now you choose on export which firmware runs on your Electribe, and the app builds the file for it.

**New for developers**
- Plugin API 12 to 25.
- Holding knobs (API 13)
  - `korg.knobHold(index, on)`: keeps knob `index` (0 to 10) from the firmware, `on` 1 holds, 0 releases. The plugin still gets `knob`. No return value.
  - `korg.knob(index, value)`: gives the firmware the value `value` (0 to 255) for the knob, as if the knob had sent it. No return value.
- Keys (API 14 and 15)
  - `korg.passKeys(key, on)`: lets key `key` (0 to 33) through to the firmware while an app is open. No return value.
  - `korg.keyHold(key, on)`: keeps the key from the firmware, also without an open app. The plugin still gets `buttonPress` and `buttonRelease`. No return value.
  - `korg.pressKey(key)`: gives the firmware a short press of the key. No return value.
- Every plugin holds its inputs for itself (API 19)
  - What a plugin keeps from the firmware (keys, knobs, pads), the runtime now keeps per plugin. The firmware gets an input back only when no running plugin holds it any more. A plugin releasing a key changes nothing for the others.
  - `korg.keyMask(low, high)`: sets all keys this plugin keeps from the firmware in one call. The Electribe has 34 keys besides the pads, numbered 0 to 33 like `korg.key.PLAY`. A number holds only 32 bits, so there are two: in `low` bit n stands for key n (0 to 31), in `high` bits 0 and 1 stand for keys 32 and 33. No return value.
- Touch pad
  - `korg.touchLockX(x)` (API 15): holds the X the firmware sees at `x` (0 to 127), -1 releases. This works for X only: Y always stays the finger's, there is no way to hold Y. The plugin still gets the real X in `touch`. No return value.
  - Setting X and Y works like this: `korg.touch(x, y)` (API 25) puts a finger on the touch pad, with raw values 0 to 1023 for both like the panel's, each further call moves it, `x` = -1 lifts it. `korg.pattern.current.mfxPadX` and `mfxPadY` (API 24, 0 to 127) set the pattern's touch pad value of the Master FX mode and send the MIDI CC like the touch pad.
- Working the panel like a finger (API 25)
  - `korg.keyDown(key)` and `korg.keyUp(key)`, `korg.padDown(pad, velocity)` and `korg.padUp(pad)`, `korg.encoder(index, delta)` and `korg.touch(x, y)` give the firmware the same messages as the panel, past holds, an open app and other plugins. None has a return value.
- Values of the playing pattern (API 21)
  - `korg.pattern.current.<value>` is a group of properties, not an object you can keep in a variable: every value is an integer you can read and set. The values: `tempo` (tenths of BPM), `swing`, `length`, `beat`, `key`, `scale`, `chordSet`, `level`, `mfxType`, `chainTo`, `chainRepeat`, `gateArp`, `syncGroup`, from API 24 also `alternate1314`, `alternate1516`, `mfxHold`, `mfxPadX`, `mfxPadY`.
  - `korg.current.<value>` could already be read, since API 15 it can also be set. `korg.pattern.current` (API 21) is the same group under a new name, as a call `korg.seq.setPatternValue(value, x)`. Setting goes through the firmware function the Pattern menu uses.
- Setting part values (API 14 to 24)
  - `korg.parts[i].<value>` (part `i` 0 to 15, every value an integer) can now be set too, as a call `korg.seq.setPartValue(part, value, x)`. It goes through the firmware function the knobs use.
  - Since API 24 a write sends the MIDI CC like the knob and opens its window. `korg.display.popups` (0 or 1) keeps the window shut for this plugin.
- Reading and writing steps
  - `korg.seq.getOn(part, step)`, `korg.seq.getGate(part, step)`, `korg.seq.getVelocity(part, step)` and `korg.seq.getNote(part, step, slot)` return an integer, `getNote` -1 for an empty slot (API 22).
  - `korg.read.patternBytes(array, pattern, offset)` copies bytes of a pattern into an array and returns their count, `korg.seq.writeSteps(array, part, first)` writes whole steps and returns the number of steps (API 14).
- Viewed and next pattern (API 18)
  - `korg.viewedPattern`: integer 0 to 249, read only. The pattern the display shows, the viewed one while you page through.
  - `korg.nextPattern`: integer 0 to 249, -1 when none is waiting, read only. The next pattern the pattern change has confirmed.
  - As calls: `korg.read.viewedPattern()` and `korg.read.nextPattern()`.
- Globals (API 20)
  - `korg.global.*`: one value for each of the 19 pages of GLOBAL PARAMETERS, such as `korg.global.midiChannel` (0 to 15) or `korg.global.metronome` (0 to 4). Each is an integer you can read and set, and it takes effect right away as in the menu.
- BLECH menu (API 17)
  - `korg.menu.blech.*`: every page of CUSTOMIZATION and FEATURES, plus SET INIT PATTERN, as an integer to read and set.
  - `korg.menu.blech.write()` writes these settings to the card like WRITE. No return value.
